# Better xCloud — Tizen TV

Protótipo experimental para Samsung TU8000 com Tizen 5.5.

## Estrutura

- config.xml: manifesto do aplicativo Tizen.
- index.html: tela inicial e diagnóstico das APIs Samsung.

## Objetivo

Adaptar o Better xCloud para funcionar como aplicativo
instalável na Samsung Smart TV.

## Estado atual

- Estrutura inicial Tizen criada.
- Diagnóstico AVPlay preparado.
- Integração com Xbox Cloud Gaming pendente.
- Compilação e assinatura WGT pendentes.

## Compatibilidade

Dispositivo de teste: Samsung TU8000.
Sistema: Tizen 5.5.
